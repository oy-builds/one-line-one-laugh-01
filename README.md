# One Line, One Laugh — Smoke Alarm

A single funny line for the make.fun "One Line, One Laugh" bounty. The program writes one original joke line (94 characters, inside the 1–200 gate) to `/output/entry.txt`.

The line: a smoke alarm that only ever goes off when its owner cooks — technically doing its job, but the timing feels personal.

Run with `node main.ts` (Node 22+). The output is deterministic: the same line, byte for byte, on every run.
